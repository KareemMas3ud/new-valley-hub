## 📖 About the Project

**New Valley Hub** is a premium, AI-powered smart tourism platform for the New Valley Governorate (الوادي الجديد) in Egypt. From the otherworldly White Desert to the ancient oasis towns of Kharga and Dakhla, we bring Egypt's hidden treasures to the world through cutting-edge technology and luxurious design.

Built for the **"New Valley Innovates" Hackathon 2026**, this Progressive Web Application showcases the perfect fusion of heritage and innovation — featuring AI-driven experiences, sophisticated UI/UX, and an offline-first architecture.

## 🔥 Key Features

### 🤖 "Am Sa3eed" (عم سعيد) — RAG-Powered AI Chatbot
Your personal AI local guide, powered by **Google Gemini** with Retrieval-Augmented Generation. Am Sa3eed searches the live database — attractions, hotels, and products — before every response, grounding answers in real platform data with a warm Egyptian personality.

### ✨ AI-Powered Trip Planner
Intelligent itinerary generator with interest-based filtering (Natural / Historical / Cultural), budget tiers, smart 2-per-day scheduling, and automatic cost calculation including ticket prices.

### 🌿 Eco-Trip Analyzer — CO₂ Carbon Footprint Calculator
SDG 13 sustainability flagship. Uses a hardcoded triangular distance matrix (15 key New Valley locations) to calculate trip CO₂ emissions across transport modes (Walking / Electric Bus / Car), with personalized Net-Zero badges and progress visualization.

### 🏺 3D Virtual Museum with Augmented Reality
Interactive 3D artifact gallery using `@google/model-viewer` Web Components. View ancient New Valley relics in 3D, or tap the AR button on mobile to place them in your real environment through your camera.

### 📸 Digital Souvenir Maker
Canvas-based photo editor with Egyptian-themed backgrounds, ancient typography fonts (Hieroglyphs), stickers, and frames. Upload a personal photo, customize it, and download as PNG or save to your dashboard.

### 🛍️ Artisan Marketplace — SDG 8
A direct economic lifeline connecting New Valley artisans to global tourists. Product cards display details, pricing, and seller contact info for peer-to-peer purchasing. Impact badges featured in the hero section.

### 🔐 JWT Authentication & Personal Dashboard
Secure registration/login with `djangorestframework-simplejwt`. Personal **My Trips** dashboard to save AI-generated eco-trips and custom souvenirs in a premium card layout.

### 🗺️ Interactive Map
Leaflet.js-powered map with clickable markers for all attractions, hotels, and services. Full offline fallback via PWA service worker.

### 🔍 Global Search
Unified search across all content types — attractions, hotels, and marketplace products — via a single API endpoint with grouped results.

### 🆘 Emergency SOS Button
Always-visible pulse-animated button with direct `tel:` links to local Ambulance, Police, and Tourist Police. Works offline.

### 📴 Progressive Web App (PWA)
Installable, offline-first architecture with `vite-plugin-pwa`. Service Worker caching, Add to Home Screen, and native-like experience on all devices.

## 🚀 Getting Started

### Prerequisites

| Tool | Required Version |
|------|-----------------|
| **Python** | 3.11 or higher |
| **Node.js** | 18 or higher |
| **npm** | 9 or higher |
| **Git** | Any recent version |

You will also need a **Google Gemini API Key** — [Get one free here](https://aistudio.google.com/app/apikey).

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/karim238253/new-valley-hub.git
cd new-valley-hub
```

---

### 2️⃣ Backend Setup

```bash
cd backend

# Create & activate virtual environment
python -m venv venv
venv\Scripts\activate           # Windows
# source venv/bin/activate      # macOS / Linux

# Install all dependencies
pip install -r requirements.txt

# Configure environment variables (see section below)
# Create backend/.env with your keys

# Run database migrations
python manage.py migrate

# (Optional) Seed the database with sample data
python seed_comprehensive.py

# (Optional) Create an admin superuser
python manage.py createsuperuser

# Start the backend server
python manage.py runserver
```

> 🟢 **Backend API available at:** `http://127.0.0.1:8000/api/`

---

### 3️⃣ Frontend Setup

Open a **new terminal** (keep backend running):

```bash
cd frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```

> 🟢 **Frontend available at:** `http://localhost:5173`

---

### 4️⃣ Access Points

| URL | Description |
|-----|-------------|
| `http://localhost:5173` | Main website (React SPA) |
| `http://127.0.0.1:8000/api/` | DRF Browsable API |
| `http://127.0.0.1:8000/admin/` | Django Admin Panel |

## 🔑 Environment Variables

Create a `.env` file inside the `backend/` directory:

```env
# Django
SECRET_KEY=your-django-secret-key
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

# Google Gemini AI (required for chatbot)
GEMINI_API_KEY=your-google-gemini-api-key

# Database (optional — defaults to SQLite for local dev)
# DATABASE_URL=postgresql://user:password@host:port/dbname

# Production (optional)
# FRONTEND_URL=https://your-production-url.com
```

| Variable | Required | Description |
|----------|----------|-------------|
| `SECRET_KEY` | ✅ | Django cryptographic signing key |
| `DEBUG` | ✅ | `True` for development, `False` for production |
| `ALLOWED_HOSTS` | ✅ | Comma-separated allowed hostnames |
| `GEMINI_API_KEY` | ✅ | Google Gemini API key ([get it here](https://aistudio.google.com/app/apikey)) |
| `DATABASE_URL` | ❌ | PostgreSQL URL (defaults to SQLite if omitted) |
| `FRONTEND_URL` | ❌ | Production frontend URL for CORS |

## 🔌 API Reference

### Authentication & User Endpoints

| Method | Endpoint | Description | Auth |
|--------|---------|-------------|------|
| `POST` | `/api/auth/register/` | Register a new user account | No |
| `POST` | `/api/auth/token/` | Login — returns JWT access & refresh tokens | No |
| `POST` | `/api/auth/token/refresh/` | Refresh an expired access token | No |
| `GET` | `/api/auth/save-trip/` | Get user's saved trips | **JWT** |
| `POST` | `/api/auth/save-trip/` | Save an AI-generated trip | **JWT** |
| `DELETE` | `/api/auth/save-trip/{id}/` | Delete a saved trip | **JWT** |
| `GET` | `/api/auth/souvenirs/` | Get user's saved souvenirs | **JWT** |
| `POST` | `/api/auth/souvenirs/` | Save a digital souvenir | **JWT** |
| `DELETE` | `/api/auth/souvenirs/{id}/` | Delete a saved souvenir | **JWT** |

### Tourism Endpoints

| Method | Endpoint | Description | Auth |
|--------|---------|-------------|------|
| `GET` | `/api/tourism/attractions/` | List all tourist attractions | No |
